DAY 2 - Drawing Shapes

PROMPT:
How do I draw a line between two points on a 2D character grid in C?

RESPONSE:
Explained step-based interpolation:
    dx = x2 - x1, dy = y2 - y1
    steps = max(|dx|, |dy|)
Loop from 0 to steps and calculate intermediate (r, c) positions using:
    c = x1 + (dx * i) / steps
    r = y1 + (dy * i) / steps
Mark each valid position with '*'.

------------------------------------------------------------
PROMPT:
How do I draw a rectangle? I want to give top-left and bottom-right coordinates.

RESPONSE:
Loop over rows r1 to r2 and cols c1 to c2.
Only mark '*' when r == r1 or r == r2 or c == c1 or c == c2
(border only, not filled).

------------------------------------------------------------
PROMPT:
How to draw a triangle using the line function?

RESPONSE:
A triangle is just 3 lines connecting 3 points:
    drawLine(x1,y1, x2,y2);
    drawLine(x2,y2, x3,y3);
    drawLine(x3,y3, x1,y1);

------------------------------------------------------------
PROMPT:
How do I draw a circle on a 2D character canvas in C?

RESPONSE:
Use the distance formula. For each cell (r, c):
    dist = sqrt((r-cy)^2 + (c-cx)^2)
If dist is close to radius (within a small threshold like 0.6), mark '*'.
Since characters are taller than wide, scale x-distance by 0.5
to keep the circle looking round:
    dx = (c - cx) * 0.5

DAY 3 - Object Storage and Rendering

PROMPT:
I want to store multiple shapes and redraw all of them after clearing the canvas.
How do I do this?

RESPONSE:
Suggested storing all objects in parallel arrays:
    int shapeType[MAX];
    int px1[MAX], py1[MAX];
    int px2[MAX], py2[MAX];
    int px3[MAX], py3[MAX];
    int count = 0;
A render() function clears the canvas then loops through all stored objects
and redraws each one.

------------------------------------------------------------
PROMPT:
How do I delete a specific object by index without clearing all shapes?

RESPONSE:
Shift all elements from idx+1 onwards one position left:
    for(i = idx; i < count - 1; i++)
        copy [i+1] into [i] for all arrays
Then decrement count and call render() to redraw remaining shapes.

DAY 5 - Compiler Errors and Final Fix

PROMPT:
I am getting this error when compiling:

main.c:10:14: error: redefinition of 'y1' as different kind of symbol
int x1[MAX], y1[MAX];
/Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/include/math.h:729:15:
note: previous definition is here
extern double y1(double)

RESPONSE:
On macOS, math.h defines y1() as a Bessel function which conflicts with
the global array named y1[].
Fix: rename all coordinate arrays to avoid the clash:
    y1[] -> py1[]
    x1[] -> px1[]
    x2[] -> px2[], y2[] -> py2[]
    x3[] -> px3[], y3[] -> py3[]
Also renamed type[] to shapeType[] to avoid any further conflicts.
